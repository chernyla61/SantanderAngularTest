# PWA Icons

This directory should contain PNG icons in the following sizes:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

You can generate these icons using an online tool like:
- https://www.favicon-generator.org/
- https://www.pwabuilder.com/

Or use your own app logo and resize it to the required dimensions.
